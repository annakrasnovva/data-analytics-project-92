
## 📊 Анализ продаж

### О проекте

Учебный аналитический проект, выполненный в рамках обучения в Hexlet.

**Цель:** проанализировать продажи магазина, оценить эффективность продавцов, изучить покупательскую активность и выявить особенности поведения клиентов.

### 🛠 Стек технологий

- **SQL / PostgreSQL:** JOIN, CTE, подзапросы, оконные функции, агрегирование данных
- **Apache Superset / Preset:** визуализация данных
- **CSV:** сохранение результатов запросов

### Выполненная работа

- Проанализировала выручку, количество операций и среднюю выручку продавцов.
- Исследовала распределение клиентов по возрастным группам.
- Изучила динамику продаж по месяцам и дням недели.
- Проанализировала покупки с нулевой стоимостью в период акции.
- Подготовила SQL-запросы, дашборд и презентацию с результатами исследования.

### 📈 Основные результаты

- В исследуемой базе — **19 759 клиентов**, около **60%** из которых старше 40 лет.
- **Топ-10 из 22 продавцов обеспечивают 76% выручки**.
- У 15 из 22 продавцов средняя выручка на операцию ниже среднего показателя по продавцам.
- Выявлена неравномерность распределения выручки между сотрудниками.

### Особенности данных
- По условиям учебного проекта таблица `customers` содержит данные о покупателях магазина. Анализ возрастных категорий проводится для этой совокупности клиентов.

### ⚠️ Ограничения анализа

- Исходные таблицы базы данных не включены в репозиторий.
- Данные за сентябрь охватывают неполный месяц.
- Анализ первых покупок в период акции требует дополнительной проверки истории клиентов.
- Наблюдаемые различия между днями недели не подтверждены статистическим тестированием.
- Выручка рассчитана на основе цены товара из таблицы products. Расчёт предполагает, что цена товара не изменялась в исследуемом периоде.
